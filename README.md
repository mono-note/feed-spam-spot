# Feed Spam Spotter

Chrome extension ที่ช่วยตรวจจับและติดป้ายกำกับโพสต์โฆษณา สแปม การขายของ ลิงก์ Affiliate, Scam และ Engagement bait บน X, Facebook และเว็บไซต์ทั่วไป พร้อมบล็อกคำขอไปยังเครือข่ายโฆษณาที่รู้จัก

การวิเคราะห์ใช้ [TypeSafe Jev](https://typesafe.ai/) โดยผู้ใช้ต้องใส่ API key ของตนเองในหน้า extension

## ความสามารถ

- ตรวจจับโพสต์บน X และ Facebook แบบอัตโนมัติ
- เว็บไซต์อื่น ๆ: ติดป้ายช่องโฆษณาที่รู้จัก (เช่น `ins.adsbygoogle`, `div-gpt-ad`, sponsored) โดยไม่เรียก API และวิเคราะห์ข้อความใน `<article>` ที่ยาวตั้งแต่ 80 ตัวอักษร
- โหมด **ซ่อนโฆษณาไปเลย**: ซ่อนโพสต์/ช่องที่เป็นโฆษณาแทนการติดป้าย
- บล็อกคำขอไปยังเครือข่ายโฆษณา (Google Ads, DoubleClick, Amazon, Criteo, Taboola, Outbrain ฯลฯ) ด้วย `declarativeNetRequest`
- แสดงป้ายกำกับภาษาไทยบนโพสต์ที่เข้าข่าย
- แยกประเภทโฆษณา สแปม ขายของ Affiliate, Scam และ Engagement bait
- ตรวจจับโพสต์ที่แพลตฟอร์มระบุว่าเป็นโฆษณาได้โดยไม่เรียก API
- จำกัดจำนวนการวิเคราะห์พร้อมกันและ cache ผลลัพธ์ภายในหน้าเว็บ
- รองรับ light/dark mode ใน popup
- เปิด–ปิดการตรวจจับจาก popup ได้ทันที โดยจำสถานะไว้และไม่ต้อง refresh หน้าเว็บ

## การติดตั้งแบบ Developer mode

1. Clone repository นี้
2. เปิด `chrome://extensions`
3. เปิด **Developer mode**
4. เลือก **Load unpacked**
5. เลือกโฟลเดอร์โปรเจกต์นี้
6. เปิด popup ของ extension แล้วใส่ TypeSafe API key
7. เปิดหรือ refresh หน้าเว็บที่ต้องการ

## การใช้งาน

1. เปิด extension จาก toolbar ของ Chrome
2. ใส่ API key ในช่อง **API key**
3. กด **Save**
4. Refresh หน้าเว็บเพื่อเริ่มตรวจสอบโพสต์

API key ถูกเก็บด้วย `chrome.storage.local` ภายในเบราว์เซอร์ของผู้ใช้ และส่งไปยัง TypeSafe API เพื่อวิเคราะห์โพสต์เท่านั้น

ใช้สวิตช์ **เปิดใช้งานการตรวจจับ** ใน popup เพื่อเปิดหรือปิดการทำงานบนทุกแท็บที่รองรับ (ค่าเริ่มต้นคือเปิด) เมื่อปิด ป้ายกำกับจะถูกนำออกและหยุดส่งคำขอวิเคราะห์ใหม่ ส่วนคำขอที่ส่งไปแล้วอาจยังทำงานต่อ แต่จะไม่แสดงป้ายกำกับ เมื่อเปิดอีกครั้งจะตรวจจับต่อทันทีโดยไม่ต้อง refresh

เปิดสวิตช์ **ซ่อนโฆษณาไปเลย** เพื่อซ่อนโฆษณาแทนการติดป้าย (ค่าเริ่มต้นคือติดป้าย) มีผลกับหน้าที่เปิดอยู่ทันที

## เว็บไซต์ที่รองรับ

- X (`x.com`, `twitter.com`) และ Facebook (`facebook.com`) — ใช้ตัวอ่านโพสต์เฉพาะของแต่ละแพลตฟอร์ม
- เว็บไซต์อื่นทั้งหมด (`<all_urls>`) — ใช้ตัวตรวจจับทั่วไปตามที่อธิบายด้านบน

ตัวเลือก DOM ของ Facebook อาจต้องปรับตามการเปลี่ยนแปลงของหน้าเว็บ เนื่องจากโครงสร้างของ Facebook เปลี่ยนแปลงได้บ่อย

## โครงสร้างไฟล์

- `manifest.json` — การตั้งค่า Chrome extension
- `background.js` — เรียก TypeSafe API และจัดการ API key
- `content.js` — อ่านโพสต์ วิเคราะห์ และแสดงป้ายกำกับ
- `popup.html` / `popup.js` — หน้าตั้งค่า API key, สวิตช์เปิด–ปิด และโหมดซ่อนโฆษณา
- `rules.json` — กฎ `declarativeNetRequest` สำหรับบล็อกเครือข่ายโฆษณา
- `icons/` — ไอคอนของ extension

## ข้อจำกัด

- ต้องมี TypeSafe API key ที่ใช้งานได้
- ความแม่นยำขึ้นอยู่กับผลลัพธ์จากโมเดลและข้อความในโพสต์
- การเปลี่ยนแปลง DOM ของ X หรือ Facebook อาจทำให้ตัวตรวจจับต้องปรับปรุง
- กฎบล็อกโฆษณาทำงานตลอดเวลา ไม่ขึ้นกับสวิตช์เปิด–ปิดใน popup
